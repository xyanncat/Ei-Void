# Ei Void 0.2.0 — developer preview

Ei Void is now one app: an assistant-first OLED shell, local-first bill
reminders with the Ei Snore Discord connection, and the Void coding-agent
workspace.

## What is in this build

- **Assistant home** — pure-black canvas, staggered menu, incognito chat,
  two horizontally scrolling task rows, a task picker, and a floating ask bar.
  A single charcoal drawer replaces the old bottom navigation. The layout now
  fits short landscape screens and respects the side navigation bar.
- **Library** — reminders with due-date pills, Upcoming/Paid filters, month
  stats, Mark paid, Snooze and exact Android alarms.
- **Ei Snore · Discord notifications** — Customize launches a Discord OAuth2
  PKCE flow, sends the one-time token to `POST /api/v1/discord/link` with the
  Clerk session, shows the linked username, and supports Disconnect and Send
  test. The app never stores the Discord token or ships the bot token.
- **Projects** — clone, edit, review and push a GitHub repository through the
  guarded on-device agent.
- **Customize and usage** — model tiers, provider keys in Keystore-backed
  storage, reminder lead time and email, notification permissions, appearance,
  plan and local usage ledger.
- **Services** — Express website and app API, Discord.js bot with a single-guild
  lock and reminder scheduler, PostgreSQL migrations, and a Render Blueprint.

## Install

Download `EiVoid-v0.2.0-debug.apk` from this release. It targets Android 13
(API 33) and newer, arm64.

This preview is **debug-signed** because release signing secrets are not
configured on the repository. Configure `ANDROID_KEYSTORE_BASE64`,
`ANDROID_STORE_PASSWORD`, `ANDROID_KEY_ALIAS` and `ANDROID_KEY_PASSWORD` to make
the release workflow publish a signed build.

## Discord setup

The Connect button needs a real Discord application and a deployed Ei Void API:

1. Enable **OAuth2 → Public Client** and add
   `https://<your-host>/discord-callback` as a redirect.
2. Set `discord.clientId` and `ei-void.apiUrl` in `android/local.properties`,
   then rebuild.
3. Run the web service with `DISCORD_APPLICATION_ID`, `DISCORD_GUILD_ID` and
   `DISCORD_BOT_TOKEN`; the bot must be in the same guild.

Without that configuration, Connect shows “Discord is not configured in this
build” rather than failing silently. That path is verified on the emulator and
the Redmi 10 Prime.

## Not live yet

- No hosted API, PostgreSQL database or Render deployment is included in this
  repository's releases. `render.yaml` is ready for the owner's Render account.
- Clerk, Discord and AI-provider credentials are not committed.
- App-to-dashboard usage sync is not enabled yet.
- Known dependency advisories remain in `zod` 3 and `nodemailer` 6; upgrading
  both is a breaking change tracked separately.
