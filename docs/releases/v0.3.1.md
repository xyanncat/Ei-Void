# Ei Void 0.3.1 — compact card copy

A small follow-up to 0.3.0.

- Capability-card descriptions are shorter, so they fit compact phones and
  larger system font scales without ellipses.
- No design, navigation or data changes. Reminders, Discord linking, projects
  and provider settings are unchanged.

Install `EiVoid-v0.3.1-debug.apk`. As with 0.3.0 this is a debug-signed preview
until Android signing secrets are configured. The interface is the production
OLED design.

Verification: Android unit suite, lint and debug build pass; the APK is
installed on the Redmi 10 Prime with the reminder database preserved.
