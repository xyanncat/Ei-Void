# Ei Void 0.3.2 — even card grid

A final layout polish for the 0.3 production UI.

- Capability cards in the same row now share the tallest height, even when a
  description wraps to one or two lines at a larger system font scale.
- The Draft a message card keeps a two-line description so the second row is
  balanced on the Redmi 10 Prime.
- No behavior, data, Discord, reminder or provider changes.

Install `EiVoid-v0.3.2.apk`. This is a signed preview build: it uses the
development key until the repository's Android signing secrets are configured.
The interface and behavior are the production OLED design.

Verification: Android unit suite, lint and debug build pass; the APK is
installed on the Redmi 10 Prime with the reminder database preserved.
